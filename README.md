Sum up 26 November's world news in one image — a make.fun bounty entry.

`main.py` copies the newspaper front page **THE GLOBAL HERALD** (Thursday 26 November 2026) to `/output/entry.png` (1024×683), byte-identical on every run. Five verified stories from 26 Nov 2026:

1. Carney shields Canada's steel and lumber from US tariffs
2. 100th Macy's Thanksgiving Day Parade faces a nor'easter
3. Solomon Islands picks Australia over China in a security pact
4. North Korea expels Switzerland's envoy
5. Bangladesh raises garment pay 36%

Run it:

```sh
python3 main.py   # writes /output/entry.png, byte-identical on every run
```
